# v0.1 main: invalid material-discovery protocol

The batch frozen at `benchmark-v0.1-main` (`6e5bd46`) is not a benchmark result.

`run-agent.mjs` passed the task text to Codex but did not tell the agent that the condition's README
and public declarations were mounted under `/materials`. The experiment therefore did not establish
its intended premise: learning an unknown DSL from the supplied materials.

All 15 runs were discarded. The private raw evidence is retained, but none of its measurements are
combined with r3. The repair added a path-only material-discovery prompt and a real-agent integration
preflight; it did not embed the material contents into the prompt.
