# v0.1 main r2: invalid final-error metric

The batch frozen at `benchmark-v0.1-main-r2` (`aef2e1b`) is not a benchmark result.

Material discovery was valid, but the evaluator parser counted conventional error summary lines and
missed diagnostic headers such as `error[eac::format::required]`. Four format failures were therefore
recorded with `final_errors = 0`.

All 15 runs were discarded and remain privately archived. The parser received a regression test and
the corrected experiment was frozen as r3.
