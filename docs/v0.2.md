# EaC v0.2 release notes

EaC v0.2 keeps the v0.1 promise — deterministic, seekable, single-writer timed experiences — and
expands what you can express within it. Nothing in this release relaxes a semantic guarantee.

The full implemented specification is [`docs/spec/v0.2.md`](spec/v0.2.md).

## Highlights

**Groups and nested transforms.** `scene.group(id, style)` creates a transformable parent whose
children keep local coordinates. World transform is `parent × translate × rotate × scale`, world
opacity multiplies, world depth adds. Evaluated leaves flatten before global z ordering, so a
descendant sorts against leaves outside its group.

**Richer deterministic motion.** Easing (`linear`, `easeIn`, `easeOut`, `easeInOut`, `cubicBezier`),
relative helpers (`moveBy`, `rotateBy`, `scaleBy`, `depthBy`), and `scaleTo`/`scaleBy`. Relative
operations resolve from the property value at their own start time, so builder call order does not
change the result.

**`followPath` and trajectories.** `trajectory.ellipse`, `orbit`, `spiral`, and `wave` are absolute
paths; `linear`, `bezier`, and `cycloid` normalize from a start and end. `followPath` is one logical
writer of the vector position property, so it never manufactures x/y conflicts with itself.

**Composition helpers.** `sequence`, `parallel`, `delay`, and `stagger` build immutable `MotionPlan`
values; `schedule(plan, { at })` lowers them to ordinary timeline writes. There is no scheduler and
no hidden cursor.

**Typed colors and styles.** `hex`, `rgb`, `rgba` produce a typed RGBA `ColorIR`. `colorTo`,
`strokeColorTo`, and `blurTo` animate appearance. Text gains font family, weight, alignment, and
letter spacing; shapes gain stroke, shadow, and corner radius.

**Local image assets.** `scene.image(id, { src, … })` embeds a project-relative PNG, JPEG, or SVG.
Paths are validated lexically and after `realpath`; remote URLs and oversized files are refused.

**Deterministic timed audio.** `scene.audio(path, { at, duration, trim, volume, fadeIn, fadeOut })`
schedules a frozen project-relative WAV on the scene timeline. `eac render` muxes checked clips into
the MP4 with ffmpeg. Every clip keeps its authored volume regardless of how many clips are mixed.

**Improved tooling.** Categorized and searchable `eac docs`, `eac inspect` with a node tree, writer
intervals, audio clips, and asset status plus `--json`, and an `eac preview` timeline with
play/pause, seek, frame stepping, speed, and keyboard controls.

**Showcase.** `examples/showcase` combines groups, trajectories, composition, typed color, a local
image, and audio at zero errors and zero warnings.

## Semantic guarantees

- **Deterministic** — same source, same assets, same version, same `t` produces the same evaluated
  state. No wall clock, no ambient randomness, no evaluation history.
- **Seekable** — every timed feature is directly evaluable at arbitrary `t`. Nothing requires replay
  from `t = 0`.
- **Strict single writer** — one logical writer per property per instant. Overlapping writers are an
  error, including `moveTo` against `followPath` and `scaleTo` against `scaleBy`. Touching intervals
  are allowed; unrelated properties stay independent.
- **Platform-neutral IR** — evaluation lives behind `evaluateScene`; the SVG renderer only lowers
  evaluated leaves.

## Deferred to v0.3+

ReactiveProperty, SimulatedProperty, explicit property composition, a second renderer, orientation
along a path (path tangent), non-WAV audio formats, waveform analysis, and audio playback inside the
HTML preview. Preview controls are external controls over pre-rendered frames — they are not a
reactive property model.

## Compatibility

`ExperienceIR` carries `version: "0.2"` and `irVersion: 2`, validated in the project loader.

- Serialized **v0.1 IR is refused** with a diagnostic naming v0.1 and directing the author to rebuild
  from a v0.2 TypeScript source. It is never reinterpreted under v0.2 semantics.
- Any other unrecognized version is refused with the version actually found.
- No migration tooling ships in v0.2; TypeScript sources are the intended durable format.
- Existing v0.1 TypeScript sources remain source-compatible where the API did not change and rebuild
  into v0.2 IR.

See [ADR 0006](adr/0006-typed-srgb-color-and-explicit-ir-version-gate.md).

## Versioning and distribution

The `@eac/*` packages and the repository root move to `0.2.0` together. They are **not published to
npm** — the version identifies the implementation an example or result was produced with.
`bench/harness` stays at `0.1.0` because it belongs to the frozen v0.1 experiment.
