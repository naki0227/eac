## 変更意図

Agentの学習可能性と自己修正能力を測定できるよう、API発見、静的検証、任意時刻評価、可視出力を
一つの小さなtoolchainとして成立させた。future scopeは実装せず、未対応propertyは明示的に失敗させる。

## 設計上の意図

依存方向は units → ir → core/checker/renderer → cli。IRへSVGやffmpeg概念を漏らさず、checkerと
rendererを分離した。Cubic Bézierに統一し、同depthはsource orderで決定する。各source fileは300行以内。

## 影響範囲

新規repositoryのため既存機能・DB・API互換性への影響なし。外部processはrender時のffmpegのみ。
CLIはsource codeや個人情報を送信せず、telemetryも実装していない。
